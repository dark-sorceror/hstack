## What runs locally

Writing tools, emoji and English autocorrect work offline. The agent bridge
provides context, search and guarded edits. It does not call a model or install
an MCP server. You choose the external tool that uses it.

## Current availability

This is a desktop-only 1.0.0 candidate, not a Community Plugins listing.
[Install from source](/start/installation) with Obsidian 1.14.4 or newer.
macOS has native verification; Windows/Linux UI checks remain outstanding.

After installation, writing features need no Node installation. Only SQL needs
an external Node runtime. See [permissions and limits](/security) before
connecting a tool to your notes.
